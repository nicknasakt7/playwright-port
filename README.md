# playwright-beam

A beginner practice project for learning end-to-end (E2E) testing with [Playwright](https://playwright.dev/) and TypeScript.

The tests run against a demo login page at [automate-test.stpb-digital.com](https://automate-test.stpb-digital.com/login/) and cover the basics: finding elements with locators, filling in forms, clicking buttons, and checking results with assertions.

## What's covered

| File | Topic |
| --- | --- |
| [tests/example.spec.ts](tests/example.spec.ts) | The default example generated by `npm init playwright` |
| [tests/lesson1.spec.ts](tests/lesson1.spec.ts) | Lesson 1: locators (`#id`, XPath, `getByPlaceholder`, `getByLabel`, `getByRole`, `getByText`, `getByTestId`) and basic assertions |
| [tests/loginPage.spec.ts](tests/loginPage.spec.ts) | Test cases for the login page |

### Login page test cases

- Default page loads with the correct title, inputs, and buttons
- Page title is shown correctly
- Valid email format is accepted
- Invalid email formats show an error message
- Valid password format is accepted
- Passwords that are too short show an error message
- Show/hide password button works
- Login with a valid email and password goes to the user list page
- Login with an invalid email or password shows an error message
- Empty required fields show error messages
- The "Create an account" link opens the register page

### Playwright features used

- `test.beforeEach` to open the login page before every test
- `test.afterEach` to save a full-page screenshot to `screenshots/` when a test fails
- Data-driven tests that loop over several invalid inputs
- Assertions such as `toHaveTitle`, `toHaveURL`, `toHaveValue`, `toHaveText`, `toBeVisible`, `toBeEnabled`, and `toBeDisabled`

## Getting started

### Requirements

- [Node.js](https://nodejs.org/) (LTS version)

### Install

```bash
npm install
npx playwright install
```

The second command downloads the browsers that Playwright uses (Chromium, Firefox, and WebKit).

## Running the tests

```bash
# Run all tests in all browsers
npx playwright test

# Run one test file
npx playwright test tests/loginPage.spec.ts

# Run in one browser only
npx playwright test --project=chromium

# Show the browser while the tests run
npx playwright test --headed

# Open the interactive UI mode
npx playwright test --ui

# Step through a test with the Playwright Inspector
npx playwright test --debug
```

> **Note:** [tests/lesson1.spec.ts](tests/lesson1.spec.ts) uses `test.only` and `page.pause()` for practice. While `test.only` is in a file, Playwright runs only that test, and `page.pause()` stops the test and opens the Inspector.

### View the report

After a run, open the HTML report:

```bash
npx playwright show-report
```

## Continuous integration

The workflow in [.github/workflows/playwright.yml](.github/workflows/playwright.yml) runs the tests on every push and pull request to `main` or `master`. The HTML report is uploaded as a build artifact and kept for 30 days.
